# NOVA UI — پروژه ۴ صفحه‌ای HTML/CSS/JS

یک وب‌سایت مدرن دارک‌تم با افکت‌های شیشه‌ای، Aurora متحرک و انیمیشن‌های روان.

## صفحات
| صفحه | فایل | توضیح |
|---|---|---|
| خانه | `index.html` | هیرو با شمارنده آمار، امکانات، تعرفه‌ها، CTA |
| ورود | `login.html` | فرم لاگین با اعتبارسنجی و نمایش/مخفی رمز |
| ثبت‌نام | `register.html` | فرم ریجستر + نوار قدرت رمز عبور |
| درباره ما | `about.html` | تایم‌لاین داستان، ارزش‌ها، تیم، آمار |
| داشبورد | `dashboard.html` | KPI، نمودار میله‌ای، دونات، جدول تراکنش |

## اجرا
فقط `index.html` را در مرورگر باز کن، یا:

```bash
cd nova-ui
python -m http.server 8000
# http://localhost:8000
```

## نکات
- احراز هویت دمو با `localStorage` است (هش FNV ساده — برای پروداکشن نیست).
- داشبورد بدون لاگین، خودکار به `login.html` ریدایرکت می‌شود.
- فونت وزیرمتن از Google Fonts؛ در صورت قطعی اینترنت، فونت سیستمی جایگزین می‌شود.
- کاملاً ریسپانسیو (منوی همبرگری + سایدبار کشویی در موبایل).
